# 通知詳細とイベント説明のMarkdown

本文は文字列ひとつで保存します。普通の文章もMarkdownとして表示します。書式モードやDB列は追加しません。

- 単独改行は段落内の空白です。
- 行末空白2個以上＋改行、またはバックスラッシュ＋改行で強制改行します。
- 空行で段落を分けます。
- 字下げ・先頭末尾の改行・行末空白は保存時に削りません。
- 通知詳細とイベント説明は共通のreact-markdown + remark-gfmで表示します。raw HTMLは扱いません。
- 画像は絶対HTTP(S) URLを使用します。プレビューを開くまで画像を読み込みません。

プッシュ通知は従来のテキストです。通知作成・編集ではPush本文と詳細本文を別々に保持し、詳細本文だけをMarkdownプレビューします。イベント説明が空白だけなら従来どおり未設定です。

APIの空白保持対応のマージ・反映後に使用します。すでに失われた空白は自動復元できません。
